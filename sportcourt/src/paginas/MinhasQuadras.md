# Minhas Quadras (`MinhasQuadras.vue`)

## 📝 Descrição Geral
Página de gestão das arenas do proprietário. Permite alternar a quadra ativa no painel, abrir o gerenciador de bloqueios de horários e cadastrar novos espaços.

## 🎨 Layout e Elementos Visuais
- **Header:** `TopbarDono`.
- **Cards de Arena:** Foto de capa, nome, localização, preço/hora e botões de atalho.

## 🌐 Integrações & API
- `api.getMinhasQuadras()`
