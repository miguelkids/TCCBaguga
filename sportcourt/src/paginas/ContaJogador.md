# Conta do Jogador (`ContaJogador.vue`)

## 📝 Descrição Geral
Página de perfil do atleta. Permite visualizar e alterar nome, foto de perfil, telefone, CPF, gênero e data de nascimento.

## 🎨 Layout e Elementos Visuais
- **Header:** `TopbarJogador`.
- **Formulário:** Inputs estilizados em dark mode grafite e verde neon.
- **Upload de Avatar:** Seletor de arquivo de imagem com prévia instantânea.

## 🌐 Integrações & API
- `api.getMe()`
- `api.atualizarPerfil(dados, arquivoFoto)`
